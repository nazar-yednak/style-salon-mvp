# Стиль салон — MVP 1

Telegram-агент для консультацій та запису клієнтів одного салону. Етап: погоджена архітектура, реалізацію й тести ще не виконано.

Для продовження роботи: [поточний контекст](memory-bank/activeContext.md), [завдання](memory-bank/tasks.md), [відкриті питання](memory-bank/open-questions.md).
