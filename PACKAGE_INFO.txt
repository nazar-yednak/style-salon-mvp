Назва: Memory Bank Student Kit
Версія пакета: 2.0 - 2026-08-27
Skill: memory-bank-autopilot
Платформи: усі локальні системи, які підтримує Codex
Призначення: нативний bootstrap Memory Bank через відкриту папку проєкту

Студент відкриває цю папку в Codex і пише «Ініціалізуй Memory Bank».
Якщо skill уже встановлений, Codex використовує його. Якщо skill відсутній,
Codex встановлює підготовлену копію з memory-bank/bootstrap/skill/ і одразу
продовжує ініціалізацію проєкту.

Пакет не містить особистих робочих файлів автора, студентських даних,
API-ключів, паролів або історії чатів.
