# Поточний контекст — Стиль салон
Оновлено 2026-10-12. Етап: погоджена документація MVP; код/тести не створені.

Один салон, два Telegram-боти, усі функції SVG. Адмін підтверджує записи; Sheets — бізнес-реєстр, Calendar — відображення, PostgreSQL — технічна пам’ять та індекс. Локальний Docker на комп’ютері власника; виконавець — власник.
Каталог демонстраційний; графік ПН–НД 10–19, обід 13–14. Правила — [business-rules.md](business-rules.md).
Погоджені Model/Context Strategy, без embeddings. План 300 × 4 = 1200 сценаріїв. AI hard $10, поділ $8/$2; базова умовна оцінка $6.795 після узгодження summary до 300 токенів.
Адмінські команди природною мовою відкладено; AI-діагностика лише вручну за потреби.
Наступний крок: посилання Drive, ID/акаунти, демонстраційні майстри, підтвердження polling, ресурси й режим без сну.
