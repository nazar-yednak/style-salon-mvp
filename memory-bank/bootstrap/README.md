# Bootstrap

Ця папка містить підготовлену копію skill для першої ініціалізації Memory Bank.

Не переносіть її вручну й не запускайте файли всередині. Відкрийте кореневу папку проєкту в Codex і напишіть: `Ініціалізуй Memory Bank`.

Після успішного запуску папку можна залишити як резервну копію для перенесення workspace між підтримуваними операційними системами.
