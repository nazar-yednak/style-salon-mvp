## Доповнення Model Strategy — 2026-10-12
| ID | Ризик | Контроль |
|---|---|---|
| R16 | Перевитрата через reasoning, довгі діалоги, retries/fallback | Ліміти токенів, коштів і всіх спроб; умовне reasoning; код для стандартних дій |
| R17 | Зміна тарифів, доступності чи параметрів моделей | Перевірка перед запуском, версія тарифу в журналі, тестування endpoint |
| R18 | Відсутній usage або подвійний облік reasoning | Позначати оцінку, звіряти фактичну вартість; не вважати невідоме нулем |
| R19 | Паралельні запити перевищують бюджет | Резервування до виклику, узгоджений облік і звірка |
| R20 | Fallback формально успішний, але змістовно неправильний | Однакова валідація основної й резервної моделі; українські тести |
| R21 | Вичерпання AI-бюджету перериває обслуговування | Код, кнопки, шаблони, адміністратор; тест режиму без AI |
