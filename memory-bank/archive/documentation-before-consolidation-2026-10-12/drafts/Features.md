# Features — MVP 1

Усі наведені функціональні напрямки є на SVG. Деталізація та критерії нижче — пропозиція для першої версії.

| ID | Функція | Критерій приймання |
|---|---|---|
| F01 | Каталог послуг, цін, тривалості та майстрів | Клієнт бачить актуальні довідники й доступних для послуги майстрів |
| F02 | AI-консультація | Відповідь спирається на базу знань; невідоме питання передається адміністратору |
| F03 | Вибір дати й часу | Пропонуються слоти з урахуванням графіка і тривалості; перед записом доступність перевіряється повторно |
| F04 | Збір і підтвердження заявки | Зібрано ім’я, телефон, послугу, майстра й час; клієнт бачить підсумок перед дією |
| F05 | Створення запису | Підтвердження містить ID і деталі лише після успішного резервування; повтор не створює дубль |
| F06 | Мої записи | Клієнт бачить тільки власні записи та актуальні стани |
| F07 | Перенесення й скасування | Зміна узгоджена з календарем; старі нагадування анульовані; результат повідомлено |
| F08 | Передача адміністратору | Складна заявка має контекст, статус і відповідального; клієнт знає про передачу |
| F09 | Адміністративне керування | Авторизований адміністратор обробляє заявки, змінює записи, ціни та графіки |
| F10 | Підтвердження й нагадування | Врахована згода; повідомлення стосується актуальної версії запису; помилка доставки видима |
| F11 | Базова статистика | Є лічильники заявок, записів і скасувань за період; завантаженість та неявки мають визначені правила обліку |
| F12 | Помилки та повторні спроби | Тимчасовий збій повторюється без дублювання; нерозв’язана помилка передається адміністратору |

## Пропозиція порядку реалізації
Спочатку детермінований цикл F01, F03–F09 та обробка помилок. Потім нагадування, AI-консультація та базова статистика. Це порядок побудови одного MVP, а не вилучення функцій зі скоупу.

## Потрібні бізнес-правила
Автоматичне чи ручне підтвердження; дозволені строки перенесення/скасування; перерви та буфери між процедурами; кількість і час нагадувань; визначення неявки; чи потрібні ресурси, крім майстра. Вони ще не затверджені.
