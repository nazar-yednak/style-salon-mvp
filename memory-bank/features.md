# Функції MVP — Стиль салон
Погоджено функціональні напрямки SVG; реалізацію не виконано.

| ID | Функція | Критерій |
|---|---|---|
| F01 | Каталог послуг і майстрів | Тестовий каталог явно позначений; активні ціни/тривалість беруться структуровано |
| F02 | AI-консультація | Лише затверджені джерела; невідоме → уточнення/людина |
| F03 | Дата й час | Графік, обід, тривалість, буфер; свіжа перевірка перед утриманням |
| F04 | Заявка | Поля й підсумок для клієнта; статус очікування адміністратора |
| F05 | Утримання й підтвердження | 30 хв; рішення адміна; достовірний успіх backend перед повідомленням |
| F06 | Мої записи | Лише власні записи й актуальні статуси |
| F07 | Перенесення/скасування | Правила часу, без втрати старого запису при невдалому перенесенні |
| F08 | Передача людині | Причина, факти й питання; контекст адміністратору |
| F09 | Адмінське керування | Кнопки/форми, перевірка ID; зміни через backend |
| F10 | Повідомлення | Підтвердження й нагадування з урахуванням згоди; дедуплікація |
| F11 | Статистика | Лічильники, завантаженість, скасування, неявки за структурованими подіями |
| F12 | Помилки | Обмежені повтори, звірка невідомого результату, сповіщення адміну |

Реалізація: детермінований цикл і права → синхронізація → нагадування → AI-консультація → статистика й пілот. Усі F01–F12 залишаються в MVP.
Точні правила: [business-rules.md](business-rules.md). План: [tasks.md](tasks.md).
