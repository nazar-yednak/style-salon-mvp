# Memory Bank Bootstrap

Цей робочий простір є студентською стартовою папкою Memory Bank.

## Команда запуску

Коли користувач просить «Ініціалізуй Memory Bank» або формулює еквівалентний запит:

1. Перевір, чи доступний skill `memory-bank-autopilot` у локальній системі skills Codex.
2. Для каталогу Codex використовуй `CODEX_HOME`, якщо він заданий. Інакше використовуй стандартну папку `.codex` у профілі поточного користувача.
3. Якщо skill уже встановлений, прочитай його `SKILL.md` і виконай ініціалізацію за його правилами.
4. Якщо skill не встановлений:
   - знайди підготовлену копію в `memory-bank/bootstrap/skill/memory-bank-autopilot`;
   - установи всю папку skill до `skills/memory-bank-autopilot` у каталозі Codex;
   - не змінюй і не видаляй підготовлену копію у workspace;
   - якщо середовище потребує дозволу на запис поза workspace, попроси одне зрозуміле підтвердження;
   - після встановлення одразу прочитай `SKILL.md` та `references/scaffold.md` і продовж ініціалізацію в цьому самому діалозі.
5. Створи лише відсутні файли Memory Bank. Збережи цю інструкцію та папку `memory-bank/bootstrap`.
6. Спочатку коротко поясни, яку інформацію про автора й проєкт потрібно отримати. Не вигадуй експертну позицію, курс або методику замість користувача.
7. Після ініціалізації повідом:
   - чи був skill уже встановлений або встановлений зараз;
   - які файли створено;
   - яке перше питання потребує відповіді користувача.

Не вимагай від користувача запускати PowerShell, Terminal, командний рядок або вручну копіювати системні файли.

## Постійна актуалізація карти та глосарія

За прямою вказівкою користувача завжди підтримуй актуальними:
- `memory-bank/documentation-map.md` — карту документації та компонентів проєкту;
- `memory-bank/glossary.md` — глосарій термінів.

При кожній зміні документації, структури, архітектури, компонентів, назв, рішень або термінів перевіряй обидва файли й одразу внось потрібні уточнення в межах тієї самої роботи. Оновлюй шляхи, посилання, власників інформації та пояснення нових або змінених термінів. Якщо змін для них немає, зайвий запис не потрібний.

Пряма заборона користувача змінювати файли або Memory Bank має пріоритет: у такому випадку лише повідом про потрібні оновлення й дочекайся дозволу.
