MEMORY BANK - СТУДЕНТСЬКИЙ ПАКЕТ

1. Повністю розпакуйте ZIP-архів.
2. Відкрийте всю розпаковану папку як проєкт у Codex.
3. Напишіть у чаті:
   Ініціалізуй Memory Bank.
4. Якщо Codex попросить дозвіл установити skill у локальне середовище,
   підтвердьте цю дію.
5. Відповідайте на запитання Codex про себе, свій курс або урок.

Як це працює:
- якщо skill уже встановлений, Codex одразу почне вести проєкт із Memory Bank;
- якщо skill відсутній, Codex знайде його копію в цій папці, встановить і
  продовжить ініціалізацію в тому самому діалозі;
- PowerShell, Terminal або ручне копіювання файлів не потрібні.

Повна покрокова інструкція міститься у файлі
Інструкція - Memory Bank для студента.pdf

Важливо: спочатку працюйте саме в розпакованій тестовій папці. Не додавайте
туди єдині копії важливих матеріалів, паролі або конфіденційні дані.
