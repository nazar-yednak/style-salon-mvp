# Запуск Memory Bank

Це підготовлена стартова папка.

Відкрийте всю цю папку як проєкт у Codex і напишіть:

> Ініціалізуй Memory Bank.

Якщо skill уже встановлений, Codex одразу використає його. Якщо skill відсутній, Codex знайде підготовлену копію в `memory-bank/bootstrap/skill/`, попросить дозвіл лише за потреби, встановить її та продовжить ініціалізацію в цьому самому діалозі.
